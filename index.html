01 / The product

Everything you already know.

Forkalope keeps the workflow recognizable on purpose. Repositories, issues, pull requests, reviews, packages, permissions, and automation should all feel like second nature.

The ambition is a complete, open alternative to the hosted Git platform developers already understand. No new vocabulary to learn. No new habits to build. Just a platform you can inspect, modify, and make your own.

Read the open-source plan →

02 / The network

Independent homes. Connected code.

One deployment can be useful. A constellation of them could be resilient, portable, and owned by the people running it.

  1. 01
    Fork the platform

    Clone the complete open-source project and configure it for your community or team.

  2. 02
    Deploy your node

    Run a capable Git home on Cloudflare’s generous free plan, or on infrastructure you control.

  3. 03
    Connect when useful

    Independent nodes can share identity, discovery, and project relationships without sharing ownership.

03 / The premise

The platform belongs to you.

Open source is more useful when it includes the home your work lives in, not only the code inside it.

✦

Forkalope is an early build. The interface, deployment model, and network protocol are all being figured out in the open.
